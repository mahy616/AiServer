# AI C# 脚本助手：项目文档入口

本项目面向流程图式视觉检测软件，为现有 C# 脚本工具增加自然语言生成和修改脚本的能力。

当前主会话负责总体需求、决策汇总和进度；专项会话负责具体方案。所有会话使用同一个工作目录：`D:\github\AiServer`。

实施阶段按两条线组织：**A：客户端／业务服务／公网**，**B：模型能力／推理部署／调用**。原 01～06 保留为技术设计文档；最终按现有软件客户端与服务端两端交付，不按实现线拆成两个互不相干的工程。

客户端沿用 C#，服务端语言独立选择。当前优先建议 Python＋FastAPI，C# 保留为候选，尚未记为用户确认；业务服务与 Ollama 推理引擎分开运行。比较与候选目录见 [实施规划第 0.5 节](docs/实施规划.md#05-服务端语言与推理引擎分别选择)。

## 新专项会话怎么开始

讨论具体设计仍可用 [跨会话协作](docs/跨会话协作.md) 的专项提示。开始实施时，分别使用实现线 A／B 文末的启动提示；各自在一个会话依次完成步骤。两线先约定最小接口，A 用 Fake 验证链路，B 直连模型验证能力；最小真实实现可用时尽早接通一次，再继续迭代。P0～P6 和 G0～G7 仅用于细化交付／证据，不要求按编号再创建多个会话。
