## 3. 文件归属

- B 线维护服务包内部 context 模块、真实 Ollama 适配实现和对应模块测试；通过共同服务发布，不另建必需的“模型业务 API”。语言选型状态见实施规划第 0.5 节，当前优先建议 Python。
- B 线维护 inference 配置模板、模型启停／验证脚本、prompts、knowledge、能力 eval 与模型报告。
- 公共内部接口与构建／依赖文件由 A 线单一维护。需要新增 Python 包或其他依赖、修改接口、初始化／关闭钩子时，在交接中写明，由 A 合入共同服务后验证；不要求向 C# 服务翻译一套 Python 实验实现。
- 公网令牌、业务任务状态机、用户数据库和正式 UI 不属于本线。模型 SDK 不会自行访问用户电脑中的宿主对象。

## 4. 单独验证和接入要求

模型运行、看图、标准库代码和有明确输入／预期的 SDK 任务可通过脚本及固定材料单独评测；真实宿主编译／设备行为需相应环境。返回全文或计数不能替代业务正确。

图文联合预算按实际模型／模板／图片处理验证，不复用旧文本字节算法；不能因只有小图成功就放开任意业务图片。每次改变模型、prompt、图片或参数记录版本与结果，必要时重验取消和容量。

交接给 A 的最小内容：实际模型／profile、配置来源、内部实现文件、可重复输入、返回与失败样例、预算可验证状态、取消／收尾约定和已知限制。A 管任务执行位，B 传播底层取消；是否释放资源由共同验收确认。

### 5.1 给 A 的文件交接

- B 实际模块：`server/src/aiserver/context/prompt_builder.py`、`input_budget.py`、`inference/ollama.py`。`PreparedPrompt` 冻结实际 messages，保留图片字节 hash、prompt 版本和材料 hash；不静默删图或裁代码。`Generation` 为实际文本／文本完成状态／结束原因／计数；不代表编译或业务通过。
- `prepare_prompt` 接收 S04 材料字段和 **已由 A 校验归属／传输的解码图片字节**；B 再做 PNG 完整性和尺寸检查，直接映射原生 images。v1 保留首次布局供复现，v2 将资料放前、任务／诊断放末尾并加强 System／类型／代码块规则；选择版本需保存到有效快照。
- `check_budget` 当前一律 `ready=false, INPUT_BUDGET_UNVERIFIED, input_tokens=None`，不信任 JSON `Verified=true`。A 的 ready／入队据此拒绝真实业务请求，不把本实验的事后计数当通用预算器。运行器的 `--controlled-experiment` 仅研发使用，不能扩展为客户端可传字段。
- `OllamaAdapter.chat` 为一次真实调用；A 在 lifespan 创建一个实例并调用 `aclose`，A 管单执行位和执行计时；取消 asyncio Task 传播到当前请求／响应读取，不自动重试。`ModelCallError.code` 供 A 映射安全任务错误；`request_finished` 只对已完整 done 但空输出等可信结束场景表示本请求结束，不能据普通异常假定资源空闲。Mock 取消关闭流通过，真实 GPU 取消／收尾仍未通过，不能启用正式自动放行策略。
- 当前实测运行时 Python 3.12.4（实现使用 `asyncio.timeout`，需 Python 3.11+），httpx 0.28.1、Pillow 11.0.0；requests 2.32.5 仅显式下载工具使用，无须进入业务运行依赖。本轮未安装包。由 A 将运行依赖与锁写入公共 pyproject，B 未改公共构建文件。
- 本轮检查尚无 `inference/contracts.py`、业务 contracts 或服务装配；B 没有另写相同职责的公共 Protocol／任务服务。A 落定义后再映射 B 的具体类型并共同实测。输出案例、失败和拒绝见阶段报告及 `.local/reports/`。
- 当前实际用 `config/inference.development.example.json`；`ModelLockPath` 的完整 digest／模板 hash 与 `ImagePolicy` 已锁。唯一已实现启动入口是 `scripts/inference/Start-Ollama.py`，无永久环境变量或开机托管。引擎只监听回环；最终模型已正常卸载，引擎仍在运行。
- 根 `.gitignore`／私人配置忽略仍由 A 维护；当前目录未初始化 Git，A 接工程时排除 `.local/`、`__pycache__/` 和真实配置。主方案、主进度、公共接口和项目文件本轮均未修改；本次按文件交接，没有向其他会话发送消息。
