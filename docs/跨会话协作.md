# 跨会话协作

更新：2026-10-23。项目已进入统一工程实施阶段。

1. 新会话先读 README、主方案、项目进度，再按任务读取源码、业务契约和正式工程运维。A/B 文档为合并前历史，不再作为当前文件归属限制。
2. 唯一工程 `D:\github\AiServer`；默认继续当前工程迭代，不另建验证工程，不向历史 A 目录复制修改。修改前重新读取相关文件，保留其他会话有效更新。
3. 用户已确认的需求与技术决策不重复索要确认。工程默认、建议、实际检查结果分别标明；仅安装成功、模型响应成功、编译通过和业务通过是不同事实。
4. HTTP 契约变化同步 `contracts/api/v1`、样例与消费者；内部行为同步实现和适当回归检查。运行流程只在运维文档维护，总体决策只在主方案维护，进度和证据只在项目进度维护。
5. 模型、图片、提示词和配置变更留版本／hash。实际 token 与容量估算分开；业务材料、图片和真实凭据不进日志、Git 或发布包。
6. 文档与源码不一致时，以核实证据修正原位置。历史专项已明确标注为历史设计，其旧的未实现状态、分线职责和严格预算前置不覆盖当前方案。
7. 无用户明确指令，不自动创建其他聊天、向其他会话发送消息或更改公网／目标机范围。日常修复和回归直接在已授权工程内完成。
