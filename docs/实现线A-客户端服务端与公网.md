## 1. 本线交付

用 Fake 代替真实模型，独立完成 C# Demo→业务 API→持久任务→结果的本机／外网链路。之后接入 B 线提供的模型实现，最后集成现有视觉软件。

负责认证、任务归属、SQLite、队列、幂等、查询、停止／超时、恢复、图片传输／格式校验／保存、公网和客户端。模型参数、提示词和真实联合预算由 B 线提供，A 线通过统一接口调用，不另写一套模型策略。

## 3. 文件归属

- A 线维护服务装配／api／jobs／storage／operations、图片传输与格式校验、Fake 实现、C# Demo 和后续宿主适配。
- A 线作为单一维护者管理服务依赖声明与锁、Demo 工程文件、外部业务 contracts 和内部抽象接口；B 线提供约定与变更需求。客户端 C# 不约束服务端语言；当前优先建议 Python，状态和候选目录以实施规划第 0.5／5 节为准。
- A 线维护 server 配置模板和公网／服务脚本，不覆盖 B 线的 inference 配置、prompts、knowledge 和模型脚本。
- 代码和接口尚未创建；这里是实现归属，不是已有功能清单。

## 4. 单独验证和能力边界

Fake 可复现延迟、取消、晚到响应、截断、失败和超时；使用真实 API／数据库／公网验证链路。Fake 的预算检查和返回代码不代表真实模型通过，ready 必须明确 Fake。

真实编译和设备测试只在对应宿主／设备环境执行。Demo 不自动执行返回代码。接口字段、图片上传上限、轮询等按实际试验修改，但先同步契约，不能让两端各解释一套。
