# 正式工程运行与交付

更新：2026-10-23。源码根 `D:\github\AiServer`，Python＋FastAPI＋SQLite，C# .NET 8 控制台 Demo。主进度见 [项目进度](项目进度.md)。

## 本机启动与停止

唯一正式入口：`scripts/server/Run.py`；它启动业务 API，并由 API 管理唯一 Ollama 进程。不要同时运行旧 `Start-Ollama.py`、系统托盘 Ollama 或第二个 API。旧实验入口仅保留用于复现历史材料。

```powershell
Set-Location 'D:\github\AiServer'
& 'C:\ProgramData\anaconda3\envs\trt_test_1013\python.exe' '.\scripts\server\Run.py'
```

默认读取私有 `config/server.local.json`，不存在时读取 `config/server.ollama.example.json`。正式模板只监听 `127.0.0.1:18080`，Ollama 为 `127.0.0.1:11434`。所有模板相对路径按源码／发布根解析；不依赖当前命令行目录。

前台 Ctrl+C 正常停机：停止收新任务，结束本轮、关闭推理传输及自有引擎。意外退出后重新运行同一入口：校验旧引擎 PID、创建时间和可执行路径，结束确认属于本工程的旧进程树后启动新实例；原未完成任务失败归档，原任务不会自动重新生成。端口被未托管实例占用则拒绝启动，不能结束无关进程。

## 用户与 Demo

```powershell
$env:PYTHONPATH = 'D:\github\AiServer\server\src'
& 'C:\ProgramData\anaconda3\envs\trt_test_1013\python.exe' -m aiserver --config 'D:\github\AiServer\config\server.local.json' user-add engineer1
$env:AISERVER_TOKEN = & 'C:\ProgramData\anaconda3\envs\trt_test_1013\python.exe' -m aiserver --config 'D:\github\AiServer\config\server.local.json' token-create engineer1
dotnet build '.\tools\ClientDemo\ClientDemo.csproj'
$env:AISERVER_BASE_URL = 'http://127.0.0.1:18080'
dotnet '.\tools\ClientDemo\bin\Debug\net8.0\ClientDemo.dll' ready
```

本轮已建立本机 `developer` 用户，其业务令牌在 `.local/access/developer.token`，可用 `Get-Content -Raw` 读入当前终端 `AISERVER_TOKEN`。不得打印到报告或提交 Git。每位真实用户单独建立账号与业务令牌；隧道 authtoken 不给用户。

Demo 命令：

- `prepare <新请求.json> --instruction <需求.txt>`；可加 `--code <代码.cs>`、`--context <上下文.json>`、`--image <截图.png>`、`--operation create|modify|explain`。
- 修复使用新请求编号，提供原需求、`--code` 候选脚本、`--feedback <诊断.txt>`、`--parent <原jobId>`。可用 `--history <JSON数组文件>` 显式携带必要历史；服务不会隐式加载父任务材料。
- `submit <请求.json>` 提交并等待，`resume <clientRequestId>` 查回；`cancel/status/result <jobId>` 和 `list` 管理任务。
- 等待时 Ctrl+C 请求停止，普通断线不等于取消。请求先保存在 `.local/client/requests`，终态 JSON 和文本保存在 `results`；修改同编号内容会冲突。

HTTP 通信在 `tools/ClientDemo/ApiClient.cs`，文件准备在 `RequestFiles.cs`，命令交互在 `Program.cs`。后续正式客户端复用协议和通信行为；net8 Demo 程序集不是 net472 插件。Demo 从不执行生成代码。

## 容量、取消和错误

模型身份锁在 `config/models/qwen3vl4b.lock.json`；启动核对引擎版本、完整模型 digest、量化、视觉能力和模板 hash。提示词、准备材料与 profile 均保存版本／hash；更改提示词或配置后重启服务。

开发机使用 4K 上下文／1024 输出／512 预留，输入目标 2560。容量算法 `conservative-estimate-v1` 采用文字权重、图片网格及余量，是保守估算，不保证所有请求一定装入。结果的 `estimatedInputTokens` 与实际 `inputTokens` 分开；引擎请求始终 `truncate:false, shift:false`，超限报 `CONTEXT_TOO_LARGE`，达到输出限制标 `OUTPUT_TRUNCATED` 并保留不完整文本。不会删图、截代码或把估算当精确计数。

当前单图 PNG ≤3MiB，长边 ≤1280，总像素 ≤786432；JSON ≤5MiB。完整工业脚本和冗长 SDK 可能被开发档位拒绝。可精简相关资料，或在目标机调整模型档位；不能假装小样证明完整任务容量。

取消或超时先落任务状态，再关闭当前推理，保持执行位；真实 provider 通过 Windows Job Object 结束自有引擎和子进程、重新启动并校验身份后放下一项。API 异常退出也会关闭其 Job Object，避免残留 GPU 子进程。恢复失败为 `recovering`，新提交拒绝，历史仍可查询。修改／解释／澄清均是新的独立任务。生成完成不代表编译或业务通过；真实 SDK 未提供时 validation 保持 `not_run`。

## 数据和运维

SQLite 位于配置 `data_directory/jobs.db`，WAL＋FULL。默认每用户最多 2 项未完成、全局 10 项、模型串行；每用户 120 次请求／分钟、提交 6 次／分钟，另有公共健康／认证失败限流。日志只含追踪号、状态和任务事件，不记录认证头、请求材料或模型正文。业务与引擎日志分别轮转，每份 5MiB、保留 5 份。

默认正文保留 7 天、幂等墓碑 30 天，启动和每小时分批清理。备份包含用户 token 的哈希、代码与图片，按私有数据保护。

先正常停止 API，再执行独占维护：

```powershell
$env:PYTHONPATH = 'D:\github\AiServer\server\src'
& 'C:\ProgramData\anaconda3\envs\trt_test_1013\python.exe' -m aiserver --config 'D:\github\AiServer\config\server.local.json' backup 'D:\github\AiServer\.local\backups\before-update.db'
```

`backup` 使用 SQLite backup API 包含 WAL，不直接复制活动 db。`restore <备份>` 仅允许目标为全新数据目录，先检查完整性；通过指向新目录的本地配置启动，不能覆盖旧库。`cleanup` 手动清理；`token-revoke <keyId>`、`user-disable <userId>` 管理凭据。`recovery-confirm --note <说明>` 是停止 API 后的人工异常兜底，不能替代核实旧模型已停止。

## NATAPP

当前 Web 入口为 `https://szzj.nat200.top`，用户已绑定并重启自己的 NATAPP 客户端；API 白名单已同步，HTTPS 健康返回 200。原 `caf365e954bd1a76.natapp.cc` 是标识地址，不能当作 Web 访问入口。平台设置 Web、本地 `127.0.0.1:18080`、开启域名 HTTPS、关闭本地 HTTPS。以后更换域名须同步 `allowed_hosts` 并重启 API。[官网域名要求](https://natapp.cn/)、[HTTPS说明](https://natapp.cn/article/https)。

本机客户端及私有配置在 `.local/natapp/`，官方 Windows AMD64 3.0.5 的 SHA256 为 `72e31dccfc8c622d81abcf9d9e868bc60404236a0302ae4097da0b339ed90b53`。启动使用 `natapp.exe -config=<config.ini绝对路径>`，不把 token 放命令行；日志默认 none，避免记录请求材料。公网调用只使用 HTTPS 和个人 API 令牌，不转发 11434、SQLite 或管理命令。

## 发布和 5080

`scripts/deployment/Build-Release.py` 生成版本包，包含服务源码、依赖锁、非私有模板、契约、部署脚本与已发布 Demo；有逐文件 SHA256 清单，不包含 `.local`、模型、实际配置、token、db 或日志。Demo 发布依赖目标机的 .NET 8 Runtime。包内 `workingTreeDirty` 标明是否来自尚未提交的修改。

目标机先准备核定的 Python 3.12 解释器，用其**绝对路径**执行 `-m pip install -r server/requirements.lock.txt`；本机仍固定使用 AGENTS 指定解释器，不替换现有环境。复制锁定版本 Ollama 与模型至 profile 指定目录，保持目录完整；不打包开发数据库和私有令牌。创建目标机自己的私有配置和账号，先沿用 4B 完成本机及公网任务。

`scripts/deployment/Install-StartupTask.ps1` 注册 Windows 开机计划任务，运行同一个 `Run.py`；禁止再注册独立 Ollama 任务。默认 SYSTEM，也支持具备 Python／模型读取和数据目录写入权限的专用账户；已有同名任务会拒绝覆盖。API 与 NATAPP 各用一个托管入口，同一隧道 token 不在开发机和目标机同时运行。目标机需要管理员安装与实际重启／无人登录验收，当前尚未执行。

升级：停服务→独占备份→保留旧发布包→部署新版本→健康／任务检查。回退使用旧发布包；若未来 schema 变更，再配套恢复升级前备份到新目录。当前 schema v1，无跨版本迁移。5080 地址、目录、运行账户尚未提供，不宣称已完成迁移。
